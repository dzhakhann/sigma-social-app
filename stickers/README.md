# Sigma — стикерпаки для Telegram

Синий маскот-«сигма» под соцсеть Sigma. Два пака: бесплатный и премиум.
Все стикеры — **512×512 PNG, прозрачный фон, белый контур** (по гайдам Telegram).

- `sigma-free/` — 16 базовых эмоций (для вирусного распространения)
- `sigma-premium/` — 16 «статусных» + острый 18+ подтир (стикеры 12–16)
- `preview_free.png`, `preview_premium.png` — превью-сетки
- `generator/` — исходники (Node + @resvg/resvg-js), можно менять/дорисовывать

---

## ⚠️ Важно про «платный» стикерпак в Telegram

**В Telegram нельзя продать обычный стикерпак напрямую.** Паки, созданные через
@Stickers, всегда бесплатны — встроенной покупки пака для пользователей нет.
Поэтому «премиум» реализуется одним из способов:

1. **Гейт по подписке приложения (рекомендую).** Публикуешь премиум-пак через
   @Stickers как обычно, но ссылку `t.me/addstickers/SigmaUltra` показываешь
   **только платным подписчикам Sigma** (внутри приложения, в разделе «Плюшки
   для Sigma+»). Технически пак открыт, но о ссылке знают только свои.
2. **Telegram Stars / бот-магазин.** Свой бот принимает оплату Telegram Stars
   и после оплаты отдаёт ссылку на пак. Монетизация — на стороне бота, не пака.
3. **Реферальная награда.** Премиум-пак как приз за приглашённых друзей / за
   уровень Aura. Бесплатно, но создаёт стимул звать людей → рост соцсети.

Бесплатный пак ставь в открытый доступ везде — это лучший органический канал:
на каждом стикере снизу белая Σ, и внизу карточки пака Telegram показывает имя
автора и ссылку.

## Как опубликовать (через @Stickers)

1. В Telegram открой бота **@Stickers** → `/newpack`.
2. Введи имя пака, например **Sigma** (для free) / **Sigma Ultra** (для premium).
3. Перетаскивай PNG **по одному** (именно как файл/документ, не как фото —
   иначе Telegram сожмёт), после каждого отправляй эмодзи из таблицы выше.
4. Загрузи все 16 → команда `/publish`.
5. Задай короткую ссылку (shortname), напр. `Sigma` → `t.me/addstickers/Sigma`
   и `SigmaUltra` → `t.me/addstickers/SigmaUltra`.
6. Для иконки пака `/setpackicon` (можно взять `05_cool.png` / `01_king.png`).

Ссылку `t.me/addstickers/Sigma` вставь в онбординг приложения и в подпись
приветственного поста — быстрый органический рост.

## Перегенерация / правки

```bash
cd stickers/generator
npm install @resvg/resvg-js   # один раз
node build.js                 # пересобрать оба пака + превью
```

- `sigma.js` — тело маскота, библиотеки глаз/ртов/пропсов.
- `build.js` — списки стикеров (эмоция = глаза + рот + пропсы). Меняй/добавляй тут.
- `render.js` — рендер PNG 512×512 и превью-сеток.

Идеи для расширения (лимит Telegram — 120 стикеров в паке): аниме-джойстик/гейминг,
музыкальные (под Rhythm-раздел), «GG», «W/L», сердечки-реакции для ленты.
